# HELEO frontend

React + Vite + TypeScript dApp for HELEO (LEO): stats, staking, the five emission buckets,
the emission chart, the whitepaper, and a deployer-only Deploy page.

## Setup

```bash
npm install
cp .env.example .env   # contract addresses, RPC URLs, Reown project ID, deployer wallet
npm run dev            # http://localhost:5173
```

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Start the dev server |
| `npm run build` | Type-check and build to `dist/` |
| `npm run lint` | Lint with oxlint |
| `npm run compile-contracts` | Compile `../Contracts/*.sol` into `src/contracts-artifacts/` |

## Structure

```
src/
├── components/
│   ├── Header.tsx         # Navigation, network switch, wallet
│   ├── Stats.tsx          # Supply, staking and emission-start stats
│   ├── Staking.tsx        # Stake / unstake / claim / compound / emergency exit
│   ├── Buckets.tsx        # Five emission buckets: claim and two-step hand-off
│   └── EmissionChart.tsx  # Halving schedule chart
├── config/                # Contract ABIs, networks, constants, bridge
├── pages/                 # Home, Whitepaper, Security, Bridge, Deploy
├── utils/                 # Formatting, contract reads, wallet helpers
└── contracts-artifacts/   # Generated by compile-contracts
```

## Networks

Ethereum mainnet and Sepolia, switchable in the header. The LayerZero bridge runs between
Sepolia and Base Sepolia.
